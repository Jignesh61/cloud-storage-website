# Cloud Storage Manager website (GitHub Pages)

This folder contains a simple static website with:
- `index.html` — homepage
- `privacy.html` — privacy policy starter template
- `terms.html` — terms of service starter template

## Before publishing
1. Replace `[YOUR SUPPORT EMAIL]` and `[YOUR LEGAL/PUBLISHER NAME]`.
2. In `privacy.html`, replace every bracketed instruction with accurate details about your actual app, data flows, storage, SDKs, retention, and deletion process.
3. Review `terms.html` for your actual features, payments, refunds, and business details.
4. Do not publish placeholder statements or claim a privacy/security practice unless your app really follows it.
5. Google OAuth verification may require a verified domain and may not accept a default `github.io` URL as proof of ownership of a domain you own. Check Google's current requirements before relying on these URLs.

## Publish with GitHub Pages
1. Create/sign in to GitHub and create a public repository, e.g. `cloud-storage-website`.
2. Upload these four files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. The homepage URL will resemble `https://YOUR-USERNAME.github.io/cloud-storage-website/`.
6. The policy URLs will be `.../privacy.html` and `.../terms.html`.

Do not add secrets, OAuth client secrets, access tokens, or private user data to this repository.
